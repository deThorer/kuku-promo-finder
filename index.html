How it works

The same pipeline as the Python tool, ported to run here:

  1. Code parses every script into numbered, timed events (E03.017 [01:12.40-01:14.90] ...).
  2. The AI picks 1-4 segments, the hook and the cliffhanger by event ID only, so it can never invent a timestamp.
  3. Code checks the hard rules: 20-45 s long, hook within 3 s, ends on the cliffhanger, no line cut in half, story order. Small fixes are automatic; anything else goes back to the AI with the measurements (up to 3 tries). If the only problem left is a promo up to 15 s too long, code cuts a chunk from the middle at line boundaries.
  4. The output is the cut list (episode + start + end per segment), plus a transcript of what the viewer sees and hears.

The full pipeline (moment bank for every episode, 147 scored episode runs, theme montages, a cold-viewer test, a judge and the final ranking) runs as the Python tool / Colab notebook: github.com/deThorer/kuku-promo-finder.
